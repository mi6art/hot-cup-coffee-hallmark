# Hot Cup Coffee

Сайт кофейни Hot Cup Coffee в Луховицах, созданный с Hallmark.

[Открыть сайт](https://mi6art.github.io/hot-cup-coffee-hallmark/)

Статический HTML, CSS и JavaScript. Сборка не требуется. Для локального просмотра: python -m http.server 8000.

Фотографии и сведения о кофейне: https://hot-cup-coffee.clients.site/ и https://yandex.ru/maps/org/hot_cup_coffee/119047507306/.
