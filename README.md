# Hot Cup Coffee

[Публичный сайт](https://mi6art.github.io/hot-cup-coffee-hallmark/)

Сайт кофейни в Луховицах. Актуальная концепция от 02.11.2026 — тёмная видеозаставка с крупным капучино, сливочная типографика, тёплый акцент и светлые разделы меню и атмосферы.

## Запуск

Статический сайт без серверной части. `python -m http.server 4180` из корня. GitHub Pages публикует корень main.

Основные файлы: index.html, cinematic.css, app.js, assets/. Готовый MP4 уже включён: assets/coffee-film.mp4 (8 секунд, 1920 × 1080, около 1,45 МБ). Постер: assets/coffee-film-poster.jpg.

## Видео

Постановочный кадр создан встроенным Image Generation, движение камеры, пар и свет собраны в Remotion. Это художественная визуализация, а не съёмка напитка в кофейне. В разделах атмосферы оставлены настоящие фотографии заведения. Исходник и промпт: [motion/VIDEO-DIRECTION.md](motion/VIDEO-DIRECTION.md).

Видео без звука; поддерживает паузу, останавливается вне экрана и при скрытии вкладки. При prefers-reduced-motion или экономии трафика автоматически не загружается. Без JS виден постер и доступны все разделы меню.
