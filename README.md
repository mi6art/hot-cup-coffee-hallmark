# Hot Cup Coffee

Сайт кофейни Hot Cup Coffee в Луховицах, созданный с Hallmark и анимацией Remotion.

[Открыть сайт](https://mi6art.github.io/hot-cup-coffee-hallmark/)

Статический HTML, CSS и JavaScript. Готовая сборка анимации включена в репозиторий; серверная часть не требуется. Для локального просмотра: python -m http.server 8000.

Фотографии и сведения о кофейне: https://hot-cup-coffee.clients.site/ и https://yandex.ru/maps/org/hot_cup_coffee/119047507306/.

## Прокрутка

Три закреплённые сцены: кофе, десерт и интерьер. Фотографии сменяются по ходу обычной прокрутки; добавлены лёгкий параллакс, появление блоков и индикатор прогресса. Колесо мыши и сенсорная прокрутка не перехватываются. При prefers-reduced-motion или высоте экрана меньше 620 px сцены показаны последовательно. Без JavaScript весь контент доступен.

## Анимация Remotion — 29 октября 2026

На первом экране живой коллаж настоящих фотографий: плавное движение карточек, типографики и круглой печати. В истории фотографии раскрываются маской, декоративная строка движется при прокрутке. Встроенный Player ставится на паузу вне экрана и при скрытии вкладки. Кнопка позволяет остановить движение. При prefers-reduced-motion коллаж неподвижен; без JavaScript остаются фото и весь контент.

Исходники композиции и инструкции по сборке: [motion/README.md](motion/README.md). Для изменения анимации: `cd motion`, `npm ci`, `npm run lint`, `npm run build:site`. Публикуется корень main через GitHub Pages.
